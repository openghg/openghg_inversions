openghg_inversions.models.scalar_sigma#

Global scalar-sigma likelihood using a reusable labelled eigenbasis.

For a fixed positive-semidefinite base covariance C0, this component evaluates C0 + sigma_global**2 I without repeating a dense factorization at every sampler step. Preparation owns alignment, eager materialization, and the one dense eigendecomposition. Model construction consumes the resulting labelled eigenbasis as a trusted numerical value.

eigenvalues,

Bases: object

Trusted labelled eigenbasis for C0 + sigma_global**2 I.

Instances returned by prepare_scalar_sigma_eigenbasis() and load_scalar_sigma_eigenbasis() have already crossed their validation boundary. Direct construction therefore assumes valid labelled arrays and metadata; it only takes an immutable eager copy of the numerical payloads.

Parameters:

  • eigenvectors (DataArray) – Square labelled matrix with dimensions (output_dim, scalar_sigma_mode).

  • eigenvalues (DataArray) – Non-negative values on scalar_sigma_mode.

  • concentration_units (str) – Physical concentration units shared by the observations, reported errors, and scalar mismatch amplitude.

  • base_covariance_sha256 (str) – SHA-256 fingerprint of the resolved A + D_obs covariance represented by this eigenbasis.

  • aggregation_error_mode (Literal['none', 'dense', 'low_rank', 'diagonal']) – Aggregation-error representation used to construct the base covariance.

  • output_dim (str) – Observation dimension represented by the rows.

load_scalar_sigma_eigenbasis(
path,
*,
observations,
observation_error,
aggregation_error,
)#

Load and align a versioned scalar-sigma eigenbasis cache.

Loading is the cache trust boundary. It validates the small xarray schema, exact dimensions, units, metadata, and ordered observation/error labels. It reconstructs the currently resolved A + D_obs once and verifies its fingerprint and aggregation-error mode before model construction.

Parameters:

  • path (str | Path) – NetCDF cache created by save_scalar_sigma_eigenbasis().

  • observations (DataArray) – Observations that will consume the cache.

  • observation_error (DataArray) – Reported errors that will consume the cache, with the same ordered labels and concentration units as observations.

  • aggregation_error (AggregationError) – Currently resolved aggregation-error representation that will consume the cache.

Returns:

Eager trusted eigenbasis aligned to observations.

Raises:

  • ValueError – If schema, dimensions, labels, units, aggregation mode, or numerical base covariance disagree.

  • OSError – If the cache cannot be opened.

Return type:

ScalarSigmaEigenbasis

scalar_sigma_base_covariance(
observations,
observation_error,
aggregation_error,
*,
output_dim='nmeasure',
covariance_dim='nmeasure_cov',
)#

Align and materialize the fixed scalar-sigma covariance once.

The observation error and selected aggregation-error payload retain their labels through exact alignment. Their dense payloads are then materialized together before forming A + D_obs.

Parameters:

  • observations (DataArray) – One-dimensional observations carrying the canonical ordered observation coordinate and a non-empty units attribute.

  • observation_error (DataArray) – Non-negative reported standard deviations in the same units and observation order as observations.

  • aggregation_error (AggregationError) – Validated aggregation-error representation for the same observations.

  • output_dim (str) – Observation dimension name.

  • covariance_dim (str) – Column dimension used by a dense covariance.

Returns:

Dense symmetric A + D_obs covariance. Preparation validates positive semidefiniteness during its single eigendecomposition.

Raises:

ValueError – If dimensions, labels, units, values, or covariance properties are invalid.

Return type:

NDArray[float64]
