openghg_inversions.rhime.standard#

Readable scientific recipe for a standard single-sector RHIME inversion.

The public recipe deliberately spells out its complete execution order. Small amounts of forwarding shared with the multisector recipe are retained so a scientist can read or copy this module without reconstructing a pipeline.

standard_model_input_names(prepared, model_spec)#

Declare arrays required by selected standard-model components.

Parameters:

  • prepared (PreparedInputs) – Backend-neutral prepared inputs.

  • model_spec (RhimeModelSpec) – Resolved standard-model component options.

Returns:

Prepared variable names selected for coordinated materialization.

Raises:

ValueError – If a selected component’s required input is absent.

Return type:

tuple[str, …]

materialize_standard_inputs(prepared, model_spec)#

Materialize selected standard inputs and enabled priors in one Dask operation.

After the shared computation, resolve backend-neutral BC periods and the selected likelihood’s minimum-error floor from retained observations. The result is the final scientific Dataset, usable for analysis or model building. Preparation and settings stay borrowed. Construction subsequently decides which state priors survive pruning.

Parameters:

  • prepared (PreparedInputs) – Borrowed canonical inputs and retained basis.

  • model_spec (RhimeModelSpec) – Scientific choices selecting the required inputs and priors.

Returns:

A shallow copy of the prepared Dataset with selected inputs and their coordinates materialized and enabled BC/floor operands resolved, plus prior parameter mappings keyed by model variable name. Unselected preparation variables remain borrowed and may be lazy; construction decides which selected priors enter the graph.

Raises:

ValueError – If the model has other than one sector or a selected input is missing.

Return type:

tuple[Dataset, dict[str, dict[str, Any]]]

build_standard_model(
model_inputs,
model_spec,
*,
priors,
likelihood_builder=None,
likelihood_kwargs=None,
sigma_alignment=None,
)#

Construct the standard scientific graph from already materialized values.

Materialize related inputs and enabled priors together before this call, for example with materialize_standard_inputs(). The model settings select components; priors supplies their numerical parameters without replacing those settings. Unrelated lazy input extensions are not consumed. Enabled BC sensitivities and likelihood floors must already be resolved; numerical materialization alone does not establish those operands. Independently supplied final arrays without producer provenance are accepted.

Parameters:

  • model_inputs (Dataset) – Resolved scientific arrays with selected inputs eager, normally returned by materialize_standard_inputs().

  • model_spec (RhimeModelSpec) – Resolved scientific choices for exactly one sector.

  • priors (Mapping[str, dict[str, Any]]) – Eager selected prior mappings keyed by x, bc, offset_latent, sigma and power. x is required; omitted unconfigured optional priors use their built-in defaults.

  • likelihood_builder (Callable[[...], TensorVariable] | None) – Optional ordinary custom likelihood callable.

  • likelihood_kwargs (Mapping[str, Any] | None) – Options expanded only into the custom likelihood.

  • sigma_alignment (SigmaAlignment | None) – Optional precomputed mismatch alignment.

Returns:

Concrete PyMC model and its one validated scientific output contract.

Raises:

  • ValueError – If selected inputs or prior parameters are lazy, a selected prior mapping or required input is missing, the model has other than one sector, likelihood choices are inconsistent, BC inputs are raw, or producer-recorded BC/floor policies conflict with the settings.

  • TypeError – If the custom likelihood returns an invalid value.

Return type:

RhimeModelBuildResult

run_standard(
*,
config_file=None,
config=None,
merged_data=None,
prepared=None,
likelihood_builder=None,
likelihood_kwargs=None,
**kwargs,
)#

Run a standard single-sector RHIME inversion.

The visible process is resolve request → acquire or accept supplied data → select observations → prepare observation errors → basis → sensitivities → assemble → materialize and resolve model inputs → build → sample → scientific output → requested outputs.

Selected basis/support files and reporting country files are checked before acquisition, including when merged data is supplied. Basis partitions and support maps are loaded at that boundary. Saved bases are rebound to current flux; basis_output_path is an exact retained-artifact destination.

Without supplied data, this runner acquires fresh data. Supplying prepared skips acquisition and preparation and joins the same materialize/build/sample sequence. It cannot be combined with merged_data.

Parameters:

  • config_file (str | Path | None) – Optional INI configuration file. Values in kwargs override values read from this file.

  • config (RhimeConfig | None) – Complete request from RhimeConfig.from_params. It is used without resolving again and cannot be combined with config_file or raw run parameters in kwargs.

  • merged_data (MergedData | None) – Optional externally supplied merged scientific data. Passing this borrowed in-memory handoff bypasses OpenGHG acquisition and resumes at observation selection, followed by error preparation on the retained population. This may derive error arrays and compute zero-error fallback diagnostics. The acquisition owner checks recorded species, domain, time window, and sector layout without mutating it.

  • prepared (PreparedInputs | None) – Optional borrowed canonical scientific inputs, including alternative or cached preparation. Bypasses acquisition and preparation.

  • likelihood_builder (Callable[[...], TensorVariable] | None) – Optional Python-only callable invoked with a completed forward-model mean and explicit error-model inputs in the active PyMC model. It must return the canonical observed variable y and create the canonical error scale epsilon. The callable is never read from configuration or stored in run/model specifications.

  • likelihood_kwargs (Mapping[str, Any] | None) – Options specific to the custom likelihood. Common scientific arrays are passed explicitly by the recipe.

  • **kwargs (Any) – RHIME run parameters using snake-case names, such as output_path, output_name, flux_sources, and x_prior. species names the primary gas or tracer used for object-store lookup and output naming. flux_sources contains OpenGHG flux source values.

Returns:

Scientific inversion output borrowing the prepared arrays, basis and sampled trace, including when output_format="none". Product functions consume this object directly; requested files are written before return. Build a model directly with build_standard_model() for graph checks.

Raises:

  • TypeError – If a likelihood builder is not callable or returns the wrong result type.

  • ValueError – If required parameters are missing, unsupported parameters are supplied, the flux-source count is invalid, or likelihood variables or requested-output compatibility are invalid.

Return type:

InversionOutput
