openghg_inversions.basis#

Basis construction, projection, and retained covariance-product interfaces.

The package provides basis-generation functions, flux-weighted preparation wrappers, prior-width projection helpers, and the public OPE-17 retained covariance-product API.

Basis operators own grid/state geometry: their bucket matrix is a prolongation from retained scalings to the native grid, not an automatic retained restriction. FluxWeightedBasis, exported here as BasisFunctions, pairs that geometry with flux for sensitivity projection and reconstruction; it does not own native covariance transforms. Project-owned workflows can compose the basis algorithms and use basis_functions_from_flat_basis to attach current-run flux without importing private preparation functions.

Native covariance actions live in openghg_inversions.native_covariance and openghg_inversions.source_covariance. The interfaces re-exported here choose a compatible restriction/prolongation pair and prepare labelled product blocks. They are low-level inputs to openghg_inversions.coherent_reduction and do not themselves construct the centred reduced likelihood or unresolved covariance.

Materialize mean-footprint times mean-flux weights for basis fitting.

All site footprint times contribute to the measurement-weighted footprint mean. Flux is averaged over its own native time axis; it is not paired to individual observation times. This named eager algorithm boundary leaves borrowed inputs unchanged.

Parameters:

  • weighting_flux (DataArray) – One selected source flux with time and the same spatial dimensions as the footprints. Callers implementing the standard RHIME policy select the first requested source.

  • abs_flux (bool) – Take absolute flux values before temporal averaging.

  • mask (DataArray | None) – Optional Boolean spatial mask; cells outside it are dropped.

Returns:

Eager spatial weights equal to mean footprint times mean selected flux.

Return type:

DataArray

basis_functions_from_flat_basis(*, flux, basis_flat, metadata=None)#

Attach resolved native flux to shared or source-specific flat labels.

Source-specific labels are selected in the flux source order. The caller owns source combination, native time alignment, and spatial compatibility. Constructors validate source labels. Inputs remain borrowed and flux payloads may remain lazy; partition geometry is materialized by the operator. Prepared basis state coordinates use region.

Parameters:

  • flux (DataArray) – Resolved native prior on the partition grid, optionally with time and source. Non-finite values are replaced with zero.

  • basis_flat (DataArray | Mapping[str, DataArray]) – Shared spatial region labels, or source-keyed partitions. For source-indexed flux, every runtime source must have a partition; extra partitions are omitted and runtime source order is retained. A flux without source is shared across all supplied partitions.

  • metadata (Mapping[str, Any] | None) – Optional namespaced metadata retained with the basis object.

Returns:

Operator paired with the current native prior, ready for projection of observation-aligned responses and gridded flux reconstruction.

Raises:

ValueError – If source labels are invalid, a runtime source partition is missing, or partition geometry cannot form a valid operator.

Return type:

FluxWeightedBasis

Use fixed InTEM outer regions and fit inner regions with an algorithm.

The InTEM outer-region file defines known outer labels. Its optional inner_region_label attribute identifies the inner inversion region; legacy files without that metadata continue to use their largest label. This inner mask is passed to basis_algorithm and then inserted back into the fixed outer map. This fitting boundary materializes a dense local geometry map after coordinate alignment; borrowed Dask/sparse inputs remain unchanged. Weight preparation has its existing eager fitting boundary.

For nested outer-domain preparation, allow_empty_inner_region=True keeps the inner label unsplit when its masked weights contain finite values but all are zero. Otherwise the selected basis algorithm handles the inner weights normally.

Parameters:

  • site_data (Mapping[str, Dataset]) – Borrowed site datasets containing footprints.

  • weighting_flux (DataArray) – Borrowed singular source flux used to fit weights.

  • start_date (str) – Start date of the inversion period.

  • basis_algorithm (str) – Algorithm used to fit the inner region. Supported values are "quadtree", "weighted", and "region_constrained".

  • domain (str) – Domain across which to calculate basis functions.

  • nbasis (int) – Desired number of inner-region basis labels.

  • abs_flux (bool) – If true, use absolute flux values when constructing weights.

  • outer_regions (DataArray) – Borrowed resolved fixed outer-region map.

  • landsea_classes (DataArray | None) – Borrowed resolved land/sea classes for weighted fitting.

  • region_classes (DataArray | None) – Region or country class field used only with basis_algorithm="region_constrained". File loading should happen before calling this helper.

  • region_allocation (Literal['weight', 'area']) – Allocation mode for region_constrained. One of "weight" or "area".

  • min_regions_per_class (int) – Minimum automatic allocation for each non-empty mapped class when using region_constrained.

  • split_acceptance (Literal['none', 'contrast_score']) – Optional split-acceptance criterion for region_constrained inner-region splitting.

  • contrast_contribution (DataArray | None) – Design contribution array used only when split_acceptance="contrast_score".

  • contrast_cell_weight (DataArray | None) – Optional prior flux or split-mass field used for contrast scoring.

  • min_contrast_delta_eig (float | None) – Optional minimum contrast delta_eig.

  • min_contrast_lambda (float | None) – Optional minimum contrast lambda.

  • contrast_tau (float | None) – Prior standard deviation of the split contrast coefficient. If omitted, tau=1 is uncalibrated.

  • contrast_sigma_design (float | None) – Optional scalar design standard deviation.

  • contrast_s_diag (DataArray | None) – Optional diagonal design covariance entries.

  • allow_empty_inner_region (bool) – If true, keep the inner label unsplit when its masked weights contain finite values but all are zero. Intended for nested outer-domain preparation.

Returns:

Basis field with fixed outer labels and generated inner labels. When allow_empty_inner_region is true and finite inner weights are all zero, its label is kept unsplit.

Translate historical basis keywords once, then call modern preparation.

Calling this adapter emits DeprecationWarning. Directory/name output conventions are deprecated in 0.9; legacy flat output remains explicitly available, with no automatic removal date. Prefer prepare_basis() for the shared generation arguments and scientific-map contracts.

fp_basis_case bypasses generation and discovers matching saved files below basis_directory/domain (default: repository basis_functions). All runtime sources are retained, separately in mapping order when split_by_sectors=True and combined otherwise. output_path is a historical root directory, with a domain subdirectory and filename derived from species, algorithm, month and outputname. It is used only for generated bases. basis_output_format="datatree" writes a retained operator/flux artifact; "legacy" writes its flat partition. output_path=None disables saving. Returns the operator bound to runtime flux with source and, where applicable, artifact-path metadata.

contrast_sigma_design=None,
contrast_s_diag=None,

Load or generate an operator and bind current flux without exporting it.

basis_path is an exact retained-artifact input (.nc or .zarr). Scientific support maps are borrowed labelled arrays; callers resolve paths and packaged resources before acquisition. Loading reuses the saved operator with current runtime flux. Reconstruction uses BasisFunctions.load to restore the complete saved object instead. Generation fits an eager numerical kernel. Callers may explicitly export the returned object with BasisFunctions.save. Borrowed inputs are not modified.

Parameters:

  • site_data (Mapping[str, Dataset]) – Site datasets with footprints used to construct weights. Unused when an artifact or partition is selected.

  • runtime_flux (DataArray) – Resolved native prior containing all retained sources on their inventory time axis, independent of observation-aligned responses. Replaces any saved prior when an operator is reused. Resolve source combination with resolve_runtime_flux().

  • weighting_flux (DataArray) – One source flux used for basis-design weights. Standard RHIME callers select the first requested source. Unused when an artifact or partition is selected.

  • domain (str) – Domain label for generated-basis metadata.

  • start_date (str) – Date attached to a generated partition’s singleton time axis.

  • nbasis (int) – Requested generated-region count; with fixed outer regions, this counts inner regions only.

  • basis_algorithm (str | None) – Generation algorithm: "quadtree", "weighted" or "region_constrained". Required only without a saved input.

  • fix_outer_regions (bool) – Fit only the inner region of outer_regions.

  • basis_path (str | Path | None) – Exact retained .nc or .zarr artifact to load. Mutually exclusive with basis_partition; either bypasses generation.

  • basis_partition (DataArray | Mapping[str, DataArray] | None) – Labelled partition, or source-keyed partitions, to bind to runtime flux. Spatial coordinates must match the flux grid.

  • landsea_classes (DataArray | None) – Resolved labelled map required for weighted fitting. Values 0 and 1 are split separately; other cells retain label 0.

Project independent grid-cell scale uncertainty onto basis states.

For membership matrix A and cell-total weights w = flux * area, the projected standard deviation is

sqrt(sum(A * (w * s)**2)) / abs(sum(A * w)).

s may be scalar, source-labelled, or gridded. A state with no weighted flux receives zero standard deviation. A state whose signed total cancels to zero while its numerator is nonzero receives NaN because its multiplicative scale uncertainty is undefined.

Parameters:

  • area_grid (DataArray) – Grid-cell areas on the operator grid.

  • flux (DataArray | None) – Optional replacement flux. The retained flux is used by default.

Returns:

Create a constrained fixed-outer basis from precomputed weights.

The largest value in the InTEM outer-region map selects the bounded inner domain. nbasis is distributed only among the inner region_classes; each distinct non-null outer-region value outside that maximum-valued inner domain receives one fixed basis label. Inner and outer class values are tagged before constrained splitting, so their final positive integer labels are globally disjoint.

calibrate_basis_prior_stdev(
basis_functions,
*,
area_grid,
target_matrix,
target_relative_stdev,
target_statistic='median-relative',
state_is_active=None,
flux=None,
)#

Calibrate grid-cell and basis-state prior widths to aggregate targets.

Calibration first projects a unit grid-cell standard deviation. For each source, linearity then gives the cell standard deviation required to match either the median target-relative SD or the ratio of mean target SD to mean absolute target total. A scalar target request is shared; a source-labelled request is selected by label. With one target per source, either statistic matches the requested value exactly.

target_matrix may contain any caller-defined target dimensions in addition to the operator grid. No countries, masks, or target percentages are built into this API.

The result includes grid_cell_prior_stdev, x_prior_stdev, state and target totals, achieved target standard deviations, achieved relative standard deviations, and explicit state/target/calibration status strings. Status zero means the target contains no absolute weighted flux; cancellation means nonzero signed weights sum to a zero target total; state_cancellation means a target depends on a basis state whose own signed total cancels to zero.

Parameters:

  • basis_functions (FluxWeightedBasis) – Retained basis artifact and operator.

  • area_grid (DataArray) – Grid-cell areas on the operator grid.

  • target_matrix (DataArray) – Caller-defined target masks or weights.

  • target_relative_stdev (DataArray | float) – Requested relative standard deviation, scalar or source-labelled.

  • target_statistic (Literal['median-relative', 'mean-total']) – Aggregate calibration statistic, either "median-relative" or "mean-total".

  • state_is_active (DataArray | None) – Optional labelled Boolean state mask. Inactive state widths are set to zero and omitted from target uncertainty, matching active-state model sampling.

  • flux (DataArray | None) – Optional replacement flux. The retained flux is used by default.

Returns:

Dataset containing calibrated widths and projection diagnostics.
