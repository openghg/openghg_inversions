openghg_inversions.postprocessing.unresolved_functionals#

Condition the unresolved part of native linear functionals on each draw.

A coherent reduction splits a native functional as Q x = Q m + D (alpha - Pi m) + Q x_perp. Retained-state draws give the first two terms. Given one posterior draw of alpha, the other model parameters and the noise parameters, Q x_perp is Gaussian with mean Q B_perp H.T (A + R)^-1 r and covariance Q B_perp Q.T - Q B_perp H.T (A + R)^-1 H B_perp Q.T, where r is that draw’s observation residual and A + R its observation covariance. Adding the mean and one draw from that covariance to each retained draw gives draws of the complete functional. Under the prior, Q x_perp is independent of alpha with covariance Q B_perp Q.T.

The observation covariance enters only through a labelled solve, so the same reconstruction works with a dense A + R (dense_solve()), with the fit’s low-rank-plus-diagonal A and fixed-OU noise (fixed_ou_solve()), or with any other representation the caller has factorized.

complete_functional_draws(
centred_state,
products,
*,
residual=None,
solve=None,
rng=None,
clipping_tolerance=1e-06,
)#

Reconstruct complete native functional draws from retained-state draws.

This is an eager numerical boundary with one solve per draw. Without a residual the draws are prior draws: the unresolved part is independent of the retained state. With a residual, each draw is conditioned on the data. Inputs are borrowed.

Parameters:

  • centred_state (xr.DataArray) – Retained-state draws alpha - Pi m on (chain, draw, state_dim), with the products’ state labels.

  • products (NativeFunctionalProducts) – Functional products of the reduction the fit used, already marginalised if the fit marginalised states.

  • residual (xr.DataArray | None) – Posterior residual draws y - E[y | alpha, beta] on (chain, draw, observation_dim), or None for prior draws. When H_alpha records units, the residual must carry the same units.

  • solve (ObservationCovarianceSolve | None) – (A + R)^-1 per draw; required with residual.

  • rng (np.random.Generator | None) – Generator for one draw from each conditional covariance. With None only conditional means are added, so the result’s spread omits the unresolved conditional variance.

  • clipping_tolerance (float) – Largest magnitude of a negative eigenvalue, relative to the largest eigenvalue of the prior functional covariance Q B Q.T = Q B_perp Q.T + D C_alpha D.T, that is clipped to zero before drawing. Roundoff is far smaller; a larger negative eigenvalue means the solve’s A is not the A of the products, and raises.

Returns:

Draws of Q x on (chain, draw, functional_dim) in the functional’s units. attrs["conditional_covariance_min_eigenvalue"] records the most negative eigenvalue clipped before drawing, relative to the largest eigenvalue of Q B Q.T (zero when none was negative).

Raises:

ValueError – If labels, units or sample axes differ, residual is given without solve, or a covariance to draw from has a relative negative eigenvalue beyond clipping_tolerance.

Return type:

xr.DataArray

fixed_ou_solve(
covariance,
site_amplitude,
*,
site_dim,
observation_index,
site_index=None,
description="low-rank-plus-diagonal A + fixed-OU noise at each draw's amplitudes",
)#

Return a per-draw solve with the fit’s fixed-OU covariance.

covariance already holds the fit’s low-rank-plus-diagonal A and fixed noise variance; each draw adds its own OU site amplitudes through FixedOuLowRank.solve(). To condition on an exact dense A instead, prepare covariance with a full-width factor of that A.

Parameters:

  • covariance (FixedOuLowRank) – The prepared fixed-OU covariance of the fit.

  • site_amplitude (xr.DataArray) – Posterior site amplitudes on (chain, draw, site_dim), labelled by the covariance’s sites. Draws are selected by chain and draw label.

  • site_dim (str) – Site dimension of site_amplitude.

  • observation_index (pd.Index) – Labels of the observation rows covariance was prepared with, in its row order.

  • site_index (ArrayLike | None) – Integer site of each row of observation_index, numbered like covariance.site_labels, for example the fit’s ou_site_index constant data. Defaults to the codes of the index’s site level when it is a MultiIndex.

  • description (str) – Account of the covariance for output metadata.

Returns:

A per-draw solve.

Raises:

ValueError – If the sites or the number of observations differ from the covariance’s, or the per-row sites differ from the covariance’s row sites. Within-site row order cannot be checked because the covariance does not keep observation times.

Return type:

ObservationCovarianceSolve
