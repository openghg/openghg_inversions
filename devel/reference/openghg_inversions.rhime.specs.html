  • min_error (Literal['percentile', 'residual'] | dict[str, float] | None | int | float) – Numeric, site-specific, or calculated minimum total-error floor.

  • min_error_options (Mapping[str, bool]) – Options for calculated floors, defaulting to pooled sites.

make_likelihood_settings(remaining, *, mismatch_model, start_date)#

Consume the selected likelihood’s external choices and resolve defaults.

The mapping is a resolver-owned working copy. Priors and power mappings are copied without copying opaque numerical payloads. Date-dependent alignment defaults use the winning requested start date.

Parameters:

  • remaining (dict[str, Any]) – Owned working options after type normalization; selected likelihood names are removed from this mapping.

  • mismatch_model (Literal['pollution_event', 'additive_sigma', 'fixed_error'] | None) – Selected built-in mismatch equation, or None for a custom likelihood with no built-in options.

  • start_date (str) – Effective request date used for an omitted period anchor.

Returns:

Complete settings for the selected likelihood, or None for custom construction. No model, numerical input or inference is constructed.

Raises:

ValueError – If the selection is unknown or options belong to another built-in likelihood or a custom likelihood.

Return type:

PollutionEventSettings | AdditiveSigmaSettings | FixedErrorSettings | None

class SectorSpec(name, flux_source, x_prior, variable_suffix, *, state_activity=None)#

Bases: object

Configuration for one separately optimised flux sector.

Parameters:

  • name (str) – User-facing sector name.

  • flux_source (str) – OpenGHG flux source used to retrieve this sector.

  • x_prior (dict[str, Any]) – Prior specification for this sector’s flux scaling factors.

  • variable_suffix (str) – Stable suffix for sector prior records, private latent variables and sector reporting names. The physical flux state and its total contribution use shared x and mu names.

  • state_activity (StateActivity | None) – Optional labelled active/fixed policy for this sector’s flux-scaling states. None still applies the default flux policy, fixing exactly-zero sensitivity columns to one.

)#

Bases: object

Scientific options used by the concrete RHIME model recipes.

Parameters:

  • species (str) – Primary gas or tracer name used for object-store lookup and output naming.

  • domain (str) – Model domain name.

  • sectors (tuple[SectorSpec, ...]) – Flux sectors included in the model. Each sector is optimized separately and is normally backed by one OpenGHG flux source.

  • use_bc (bool) – Whether boundary-condition scaling is included.

  • bc_freq (str | None) – Boundary-condition scaling period; None uses one period.

  • bc_freq_anchor (str | datetime | datetime64 | Timestamp | None) – Anchor for fixed-duration boundary-condition periods, normalized to an ISO string (UTC for timezone-aware values). None anchors periods to the earliest retained observation timestamp.

  • likelihood (PollutionEventSettings | AdditiveSigmaSettings | FixedErrorSettings | None) – Resolved built-in likelihood settings, or None when a Python-only custom likelihood owns that step.

  • add_offset (bool) – Whether model-data offsets are included.

  • bc_prior (dict[str, Any] | None) – Prior specification for boundary-condition scaling factors.

  • offset_prior (dict[str, Any] | None) – Prior specification for optional offsets.

  • offset_args (dict[str, Any] | None) – Extra keyword arguments forwarded to the offset component.

  • bc_state_activity (StateActivity | None) – Optional active/fixed policy for the boundary- condition scaling vector. None samples states with nonzero sensitivity and retains fixed values for structurally absent states. Supplying a policy can fix or group additional states.

  • state_activity (StateActivity | None) – Optional labelled active/fixed state policy shared by flux sectors. The default retains exact-zero pruning.

class RhimeOutputSpec(
output_format='inv_out',
output_path=None,
output_name='rhime',
save_trace=False,
save_inversion_output=True,
country_file=None,
paris_postprocessing_kwargs=None,
output_filename_convention='rhime',
)#

Bases: object

Output settings for a RHIME run.

Parameters:

  • output_format (Literal['none', 'inv_out', 'basic', 'paris', 'legacy']) – Output mode. "inv_out" saves/returns the modern inversion output, "basic" and "paris" additionally create derived outputs, "legacy" creates the old HBMCMC-compatible NetCDF product from modern RHIME output, and "none" skips output products.

  • output_path (Path | None) – Directory for saved outputs.

  • output_name (str) – Base output name.

  • save_trace (Path | bool) – Trace save setting. If true, save to output_path using the default trace file name; if a path, save there.

  • save_inversion_output (Path | bool) – Inversion-output save setting. Runner parameter normalization defaults this to true for output_format="inv_out" and false for derived product formats.

  • country_file (Path | None) – Optional country mask file used by derived outputs.

  • paris_postprocessing_kwargs (dict[str, Any] | None) – Extra keyword arguments for PARIS output creation.

  • output_filename_convention (Literal['rhime', 'legacy']) – Filename convention for derived products. Defaults to "rhime"; select "legacy" explicitly to use the independently supported legacy filename convention.

classmethod from_params(params, *, multisector)#

Resolve output choices without writing products or mutating inputs.

The active format determines the omitted inversion-output save setting. Remaining omitted values use the record’s declared defaults. PARIS option containers are owned; opaque numerical payloads remain borrowed.

Relative filesystem paths resolve from the invocation working directory; already resolved absolute paths pass through unchanged. File frontends must supply paths resolved against their own documented file base.

Parameters:

  • params (Mapping[str, Any]) – Canonical output option names after invocation overrides. Format and filename-convention values are case-insensitive.

  • multisector (bool) – Whether to enforce the multisector output restrictions.

Returns:

Validated output choices ready for inspection before execution.

Raises:

ValueError – If format, path or recipe choices are inconsistent.

Return type:

RhimeOutputSpec
