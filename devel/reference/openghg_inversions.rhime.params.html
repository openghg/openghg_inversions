openghg_inversions.rhime.params#

RHIME option resolution and complete requested configuration.

The INI frontend decodes file options; callers apply overrides and consume recipe-specific options before canonical resolution. Resolution constructs the complete requested configuration before acquisition; retained run metadata is derived only after preparation. The concrete configuration and its composed values own supported names and defaults; scientific callable signatures do not define the external schema.

Resolved acquisition and preparation choices, independent of inference.

External options enter through from_params. Ordinary option containers are owned; numerical payloads remain borrowed. Direct construction expects resolved values and does not copy or execute scientific work.

Resolve acquisition and preparation options without constructing other groups.

Unknown or wrong-phase names fail. An explicit split_by_sectors must agree with the selected multisector recipe. Select the data mapping from group_params first when consuming a shared configuration file.
