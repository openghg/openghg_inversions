openghg_inversions.rhime#

Public RHIME runners, specifications, builders, and orchestration stages.

Use run(..., model="standard") with an explicit model selection, or the prepared-input entry points for complete runs. Copied runners may use the supported resolve, acquire, observation-error, filter, basis, sensitivity, assembly, alignment, materialization, build, sample, result, and output stages directly. Alignment is pure; acquisition may access data, model materialization crosses the eager backend boundary, sampling executes PyMC, and output stages may write requested products.

run(*, model='standard', **kwargs)#

Run the selected model with its ordinary recipe arguments.

Parameters:

  • model (str) – standard (default), multisector, nested, co2, co2_cached_sigma, co2_o2 or co2_o2_cached_sigma.

  • **kwargs (Any) – Forwarded unchanged to the selected recipe. Standard, multisector and nested accept their existing INI/Python inputs. Ordinary CO2 accepts its configured prepared-input product request. Cached and linked CO2-family recipes require prepared_inputs; selection does not add acquisition or checkpoint routes.

Returns:

The selected recipe’s scientific result. Standard and multisector return InversionOutput, ordinary CO2 returns Co2Output, nested returns NestedOutput with two native output views, and cached/linked CO2 recipes return an inference DataTree.

Raises:

  • ValueError – If the model name is unsupported.

  • TypeError – If arguments do not match the selected recipe’s interface.

Return type:

Any

See the concrete recipe for scientific options, ownership and output behavior. Standard, multisector and nested callers may supply prepared to skip preparation.

Run a standard single-sector RHIME inversion.

The visible process is resolve → acquire or accept supplied data → observation errors → filter → basis → sensitivities → assemble → materialize → build → sample → scientific output → requested outputs.

Selected basis/support files and reporting country files are checked before acquisition, including when merged data is supplied. Basis partitions and support maps are loaded at that boundary. Saved bases are rebound to current flux; basis_output_path is an exact retained-artifact destination.

Without supplied data, this runner acquires fresh data. Supplying prepared skips acquisition and preparation and joins the same materialize/build/sample sequence. It cannot be combined with merged_data.

Parameters:

  • config_file (str | Path | None) – Optional INI configuration file. Values in kwargs override values read from this file.

  • config (RhimeConfig | None) – Complete request from RhimeConfig.from_params. It is used without resolving again and cannot be combined with config_file or raw run parameters in kwargs.

  • merged_data (MergedData | None) – Optional externally supplied merged scientific data. Passing this borrowed in-memory handoff bypasses OpenGHG acquisition and resumes at observation-error preparation. This may derive error arrays and compute zero-error fallback diagnostics. The acquisition owner checks recorded species, domain, time window, and sector layout without mutating it.

  • prepared (PreparedInputs | None) – Optional borrowed canonical scientific inputs, including alternative or cached preparation. Bypasses acquisition and preparation.

  • likelihood_builder (Callable[[...], TensorVariable] | None) – Optional Python-only callable invoked with a completed forward-model mean and explicit error-model inputs in the active PyMC model. It must return the canonical observed variable y and create the canonical error scale epsilon. The callable is never read from configuration or stored in run/model specifications.

  • likelihood_kwargs (Mapping[str, Any] | None) – Options specific to the custom likelihood. Common scientific arrays are passed explicitly by the recipe.

  • **kwargs (Any) – RHIME run parameters using snake-case names, such as output_path, output_name, flux_sources, and x_prior. species names the primary gas or tracer used for object-store lookup and output naming. flux_sources contains OpenGHG flux source values. Legacy emissions_name is accepted only as a compatibility alias when flux_sources is absent.

Returns:

Scientific inversion output borrowing the prepared arrays, basis and sampled trace, including when output_format="none". Product functions consume this object directly; requested files are written before return. Build a model directly with build_standard_model() for graph checks.

Raises:

  • TypeError – If a likelihood builder is not callable or returns the wrong result type.

  • ValueError – If required parameters are missing, unsupported parameters are supplied, the flux-source count is invalid, or likelihood variables or requested-output compatibility are invalid.

Return type:

InversionOutput

The visible process is resolve → acquire or accept supplied data → observation errors → filter → basis → sensitivities → assemble → materialize → build → sample → scientific output → requested outputs. This module keeps source layout validation and sector-aware outputs beside that process instead of hiding them behind standard/multisector branching.

Selected basis/support files and reporting country files are checked before acquisition, including when merged data is supplied. Basis partitions and support maps are loaded at that boundary. Saved bases are rebound to current flux; basis_output_path is an exact retained-artifact destination.

Without supplied data, this runner acquires fresh data. Supplying prepared joins the same materialize/build/sample sequence without acquisition or preparation.

Parameters:

  • config_file (str | Path | None) – Optional INI configuration file. Values in kwargs override values read from this file.

  • config (RhimeConfig | None) – Complete request from RhimeConfig.from_params. It is used without resolving again and cannot be combined with config_file or raw run parameters in kwargs.

  • merged_data (MergedData | None) – Optional externally supplied source-resolved merged scientific data. Passing this in-memory handoff bypasses OpenGHG acquisition and resumes at observation-error preparation after validating recorded species, domain, time window, and sector layout.

  • prepared (PreparedInputs | None) – Optional borrowed canonical inputs and retained basis. Cannot be combined with merged_data.

  • likelihood_builder (Callable[[...], TensorVariable] | None) – Optional Python-only callable invoked with a completed forward-model mean and explicit error-model inputs in the active PyMC model. Run a standard one-source RHIME inversion on nested native grids.

Nested options may be supplied directly or in the INI file. Ordinary options use the same modern vocabulary as run_standard(). output_format='none' returns the sampled result without formatted products and writes no result artifacts; output_format='paris' creates separate native-grid flux products and one shared concentration product.

Returns:

Native scientific views borrowing the prepared arrays and one trace. PARIS writes requested products, two output artifacts and one shared trace according to the configured export settings before returning.

Raises:

class PreparedInputs(inv_inputs, basis_functions, site_metadata)#

Bases: object

Modern RHIME preparation and durable serialization contract.

Site labels and site-aligned metadata are owned by site_metadata. Integer inv_inputs.site_indicator values are derived as zero-based project-schema positions into its site coordinate; they are distinct from CF compression-by-gathering indexes. The invariant is site_metadata.site[site_indicator] == nmeasure.site. site_names remains available in memory for existing model code, but is regenerated from site_metadata rather than serialized.

Parameters:

  • inv_inputs (Dataset) – Canonical inversion inputs consumed by RHIME model builders.

  • basis_functions (FluxWeightedBasis) – Retained flux basis object used to derive output-boundary basis and flux arrays.

  • site_metadata (Dataset) – Dataset indexed by the authoritative site coordinate. Every variable contains exactly one value per site, and averaging_period is required. Observation metadata that is genuinely constant per site may also be stored here. Values that vary within a site, such as satellite or aircraft release locations, must instead remain observation-aligned arrays. Such arrays may be carried alongside the inversion arrays without implying that model builders consume them.

Raises:

ValueError – If site metadata, measurement indexing, or multi-source labels are inconsistent.

Construct and validate durable, backend-neutral RHIME model inputs.

The stage attaches domain metadata to shallow per-site copies, assembles observation-aligned arrays, applies the satellite boundary-condition scaling, and retains basis and site metadata. It also preserves the legacy construction of the minimum-error floor and boundary-condition temporal parameterization. Those are inverse-model settings, not properties of the acquired data; moving them to their model components is a later semantic change. Core payloads are jointly materialized before invalid observations are dropped; backend selection and densification happen separately.

Parameters:

  • site_data (Mapping[str, Dataset]) – Per-site datasets from sensitivity construction. Domain metadata is attached to shallow copies, leaving these datasets unchanged.

  • basis_functions (FluxWeightedBasis) – Basis and prior fluxes to retain with the inputs.

  • site_options (SiteOptions) – Selectors for the retained sites, as returned by filter_observations().

  • domain (str) – Domain label attached to the assembled site data.

  • start_date (str) – Requested start date used to anchor temporal parameters.

  • bc_freq (str | None) – Frequency of boundary-condition scaling parameters; None keeps one period across the run.

  • min_error (Literal['percentile', 'residual'] | dict[str, float] | None | int | float) – Minimum observation-error floor as a numeric value or a mapping covering every retained site, or the named "residual" or "percentile" calculation.

  • min_error_options (Mapping[str, Any] | None) – Resolved mapping with boolean by_site, as supplied by RhimeConfig. None uses a shared calculation. Explicit keyword calls must supply already-normalized options.

  • use_bc (bool) – Whether missing boundary-condition inputs should be checked.

Returns:

Validated, backend-neutral inputs with observation-aligned arrays, retained basis functions and site metadata. Core assembly payloads are eager, possibly sparse; unselected extensions may remain lazy.

Raises:

  • ValueError – If assembled inputs fail their alignment or scientific input contracts.

  • KeyError – If the resolved by_site option is absent.

Return type:

PreparedInputs

Run a source-resolved multisector inversion.

The visible process is resolve → acquire or accept supplied data → observation errors → filter → basis → sensitivities → assemble → materialize → build → sample → scientific output → requested outputs. This module keeps source layout validation and sector-aware outputs beside that process instead of hiding them behind standard/multisector branching.

Selected basis/support files and reporting country files are checked before acquisition, including when merged data is supplied. Basis partitions and support maps are loaded at that boundary. Saved bases are rebound to current flux; basis_output_path is an exact retained-artifact destination.

Without supplied data, this runner acquires fresh data. Supplying prepared joins the same materialize/build/sample sequence without acquisition or preparation.

Parameters:

  • config_file (str | Path | None) – Optional INI configuration file. Values in kwargs override values read from this file.

  • config (RhimeConfig | None) – Complete request from RhimeConfig.from_params. It is used without resolving again and cannot be combined with config_file or raw run parameters in kwargs.

  • merged_data (MergedData | None) – Optional externally supplied source-resolved merged scientific data. Passing this in-memory handoff bypasses OpenGHG acquisition and resumes at observation-error preparation after validating recorded species, domain, time window, and sector layout.

  • prepared (PreparedInputs | None) – Optional borrowed canonical inputs and retained basis. Cannot be combined with merged_data.

  • likelihood_builder (Callable[[...], TensorVariable] | None) – Optional Python-only callable invoked with a completed forward-model mean and explicit error-model inputs in the active PyMC model. It must return the canonical observed variable y and create the canonical error scale epsilon. The callable is never read from configuration or stored in run/model specifications.

  • likelihood_kwargs (Mapping[str, Any] | None) – Options specific to the custom likelihood. Common scientific arrays are passed explicitly by the recipe.

  • **kwargs (Any) – RHIME run parameters using snake-case names. Multi-sector runs require at least two flux_sources and may include a complete sector_priors mapping keyed by sector name. When model sector labels differ from OpenGHG source values, pass sector_sources as a one-to-one mapping from sector name to one unique value in flux_sources. Legacy emissions_name is accepted only as a compatibility alias when flux_sources is absent.

Returns:

Scientific inversion output borrowing preparation and trace, even when output is disabled. Use scientific product functions for in-memory diagnostics.

Raises:

  • TypeError – If a likelihood builder is not callable or returns the wrong result type.

  • ValueError – If required parameters are missing, unsupported parameters are supplied, fewer than two flux sources are provided, or likelihood variables or requested-output compatibility are invalid.

Return type:

InversionOutput

Run a standard one-source RHIME inversion on nested native grids.

Nested options may be supplied directly or in the INI file. Ordinary options use the same modern vocabulary as run_standard(). output_format='none' returns the sampled result without formatted products and writes no result artifacts; output_format='paris' creates separate native-grid flux products and one shared concentration product.

Parameters:

  • config_file (str | Path | None) – Optional INI file; raw keyword options override its values.

  • config (RhimeConfig | None) – Resolved outer request, mutually exclusive with config_file and ordinary raw options. Inner preparation options may accompany it.

  • prepared (NestedRhimePreparedInputs | None) – Borrowed native-grid handoff; skips acquisition and preparation and is validated before the shared build/sample/output sequence.

  • inner_state_activity (StateActivity | None) – Optional policy for the inner state block.

  • likelihood_builder (Callable[[...], TensorVariable] | None) – Optional ordinary custom likelihood callable.

  • likelihood_kwargs (Mapping[str, Any] | None) – Options for that callable.

  • **kwargs (Any) – Outer RHIME options and inner acquisition/basis/time selectors. inner_domain is required for fresh preparation. inner_x_prior defaults to the outer prior. Explicit values, including None, override file settings.

Returns:

Native scientific views borrowing the prepared arrays and one trace. PARIS writes requested products, two output artifacts and one shared trace according to the configured export settings before returning.

Raises:

  • ValueError – Configuration sources conflict, preparation options accompany supplied prepared inputs, or the model/output selection is unsupported.

  • TypeError – The likelihood builder or sampler is invalid.

  • FileNotFoundError – A selected resource does not exist.

Return type:

NestedOutput
