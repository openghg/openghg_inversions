Coherent Gaussian Reduction#

The coherent-reduction API turns one labelled native covariance projection into an exact retained Gaussian model. It is a backend-neutral preparation operation: PyMC and analytic model builders may consume its result, but the operation does not construct either backend.

Let the native scaling state and observation model be

\[x \sim \mathcal N(m, B), \qquad y = Hx + \epsilon, \qquad \alpha = \Pi x.\]

Here \(\epsilon\) is independent of \(x\), and \(R\) denotes its valid observation-plus-model-error covariance in the prepared observation representation.

The Native Covariance Projection projection constructs \(C_\alpha = \Pi B\Pi^\mathsf{T}\), \(H_\alpha\), and \(HBH^\mathsf{T}\). Coherent reduction constructs those linked products locally, then returns

\[H_\alpha = HB\Pi^\mathsf{T}C_\alpha^{-1}\]

without constructing an inverse, then returns the centred conditional model

\[y \mid \alpha \sim \mathcal N\!\left( Hm + H_\alpha(\alpha - \Pi m), R + A \right),\]
\[A = HBH^\mathsf{T} - H_\alpha C_\alpha H_\alpha^\mathsf{T}.\]

All three retained quantities—the prior, effective forward operator, and unresolved covariance—come from the same product set.

The retained projection strategy supplies \(\Pi\), by one of two routes:

  • PreserveBucketProlongation(U) holds a basis prolongation \(U\) and constructs the compatible restriction \(\Pi_U\) using \(B\), so that the covariance-derived prolongation \(U_*\) equals \(U\).

  • SuppliedRestriction(Pi) holds a physical restriction chosen independently of \(B\); no basis prolongation is needed.

Either way, the restriction and prolongation are related through \(B\); they are not generally transposes of one another.

Preparing the exact result#

Pass the native covariance, a retained projection strategy, labelled native mean, and sensitivity through one operation. The bucket strategy holds a basis operator’s canonical prolongation; SuppliedRestriction instead holds a physical restriction (see Native Covariance Projection):

from openghg_inversions.basis import PreserveBucketProlongation
from openghg_inversions.coherent_reduction import reduce_native_gaussian

reduction = reduce_native_gaussian(
    covariance=covariance,
    strategy=PreserveBucketProlongation(basis_prolongation),
    state_dim="state",
    native_mean=native_mean,
    native_sensitivity=native_sensitivity,
    observation_dim="observation",
)

retained_mean = reduction.retained_mean
retained_covariance = reduction.retained_covariance
effective_operator = reduction.effective_observation_operator
unresolved_covariance = reduction.unresolved_observation_covariance

Calling reduce_native_gaussian computes any Dask-backed mean and sensitivity together. The strategy computes its own inputs, and the returned xarray arrays are eager with explicit retained-state and observation labels.

Preparing CO2 model inputs#

The CO2-only model has a dedicated public handoff that keeps the linked reduction products together with canonical RHIME observations, basis data, and site metadata. Load the canonical inputs from a checkpoint produced by the RHIME terminology and prepared-input reference workflow:

from openghg_inversions.inversion_data import PreparedInputs
from openghg_inversions.models.fixed_ou import fixed_ou_mismatch_covariance
from openghg_inversions.rhime.co2 import prepare_co2_inputs

canonical_inputs = PreparedInputs.load("base-prepared-inputs.zarr")
observations = canonical_inputs.inv_inputs
reference = fixed_ou_mismatch_covariance(
    observations["mf"], observations["mf_error"], fixed_site_amplitudes=2.0, amplitude_units="ppm",
)
co2_inputs = prepare_co2_inputs(
    canonical_inputs,
    reduction,
    reference_covariance=reference,
)

The returned Co2PreparedInputs artifact uses a low-rank-plus-diagonal representation by default, with the rank chosen from the unresolved covariance’s whitened spectrum (WhitenedRankRule; see CO₂ model recipes) and capped at the observation count. The rule needs a reference mismatch covariance chosen by the caller, here an independent 2 ppm amplitude on top of the reported observation error. Pass aggregation_error_rank=None to keep reduction.unresolved_observation_covariance as an exact dense aggregation covariance. The artifact records one representation, and the CO2 runners use it without a separate mode argument. This handoff does not alter the prepared-input contracts of the standard, or multisector paths.

For benchmarking, request an explicit low-rank-plus-diagonal (LRPD) rank at the handoff. With a reference_covariance, preparation warns when it is below the whitened-spectrum rule rank:

co2_inputs = prepare_co2_inputs(
    canonical_inputs,
    reduction,
    aggregation_error_rank=40,
)

This factorization is downstream of coherent reduction: it does not make the reduction approximate or change the retained prior and effective operator. Let \(n\) be the observation count and \(r\) the retained rank. The current preparation path materializes the complete dense \(n \times n\) covariance and computes a full dense eigendecomposition. When a reference_covariance is also supplied, it first materializes the dense reference, factorizes it and computes the dense whitened eigenvalues; this runs for an integer rank too, so the override is checked against the rule and recorded. A bare integer rank, as in the example above, skips the reference, the whitened eigenvalues and the rank-selection record. These steps are \(O(n^3)\) and need \(O(n^2)\) peak storage. The saved factor and diagonal use \(O(nr+n)\) storage. For an ordinary diagonal-plus-factor likelihood, Woodbury evaluation uses \(O(nr^2+r^3)\) work. Reducing \(r\) therefore shrinks the artifact and downstream structured-likelihood work; it does not make preparation matrix-free or avoid the dense eigendecomposition.

The default rank rule is a screening heuristic, not an adequacy claim. The rank it selects depends on the reference covariance, and choosing the reference or overriding the rank remains a caller-owned numerical and scientific decision. LRPD preparation preserves the dense covariance diagonal up to accepted roundoff and diagonal-tail clipping, reported by diagonal_preservation_error. It does not automatically certify that a rank is adequate for a particular likelihood. Compare the approximate and dense total likelihood covariance or log density over representative error profiles. Inspect the recorded retained-spectrum and reconstruction metrics directly:

diagnostics = co2_inputs.provenance["aggregation_error"]
retained_fraction = diagnostics["retained_positive_spectral_fraction"]
relative_error = diagnostics["relative_frobenius_reconstruction_error"]
diagonal_error = diagnostics["diagonal_preservation_error"]

These diagnostics describe the covariance approximation; they do not certify that the chosen rank is adequate for a particular likelihood.

See Migrating diagonal aggregation error for older inputs that contain only aggregation-error standard deviations.

Complete native functionals#

The same reduction splits the native state as \(x = m + U_*(\alpha - \Pi m) + x_\perp\), where \(U_* = B \Pi^T C_\alpha^{-1}\) and \(x_\perp\) is independent of \(\alpha\) with covariance \(B_\perp = B - U_* C_\alpha U_*^T\). A native linear functional \(Q\), such as a country total, therefore splits as \(Q x = Q m + D(\alpha - \Pi m) + Q x_\perp\) with \(D = Q U_*\). Retained-state draws give only the first two terms. \(Q x_\perp\) carries both variance and a data-driven mean update, because it is correlated with the unresolved observation error \(H x_\perp\); both are largest when retained regions cross the functional’s borders.

Pass the functionals to the reduction to prepare the products that condition \(Q x_\perp\):

reduction = reduce_native_gaussian(
    ...,
    functionals=country_functionals,  # (functional_dim, *native_dims)
    functional_dim="country_functional",
)
products = reduction.functional_products

products holds \(Q m\), \(D\), \(Q B_\perp H^T\) and \(Q B_\perp Q^T\). They are computed from bounded blocks of \(B Q^T\); \(B\) is never densified. Use one functional row per reported term, for example one country total per source, so that the joint covariance of terms is available and sums are formed per draw.

For a posterior draw of \(\alpha\), any other parameters \(\beta\) and the noise parameters, with residual \(r = y - y_0 - H_\alpha(\alpha - \Pi m) - G\beta\),

\[Q x_\perp \mid \alpha, \beta, y \sim N\left(Q B_\perp H^T (A + R)^{-1} r,\; Q B_\perp Q^T - Q B_\perp H^T (A + R)^{-1} H B_\perp Q^T\right).\]

Under the prior, \(Q x_\perp \sim N(0, Q B_\perp Q^T)\) independently of \(\alpha\). For a Gaussian retained state and the exact \(A\), the complete functional mean and covariance equal the native-grid Gaussian posterior for any retained partition. With a LogNormal retained state the conditioning on each draw remains exact under the reduced model, but the reduced model is the moment-matched approximation described in Assumptions and limitations, so the result is not the native-grid posterior of a LogNormal native field. openghg_inversions.postprocessing.unresolved_functionals.complete_functional_draws() adds the conditional mean and one conditional draw to each retained draw. It takes \((A + R)^{-1}\) as a labelled solve whose observation labels must equal the residuals’: dense_solve() for one fixed dense covariance, whose labelled columns are aligned to its rows and checked for symmetry, or fixed_ou_solve() for the fit’s low-rank-plus-diagonal \(A\) with each draw’s fixed-OU amplitudes, selected by chain and draw label. FixedOuLowRank keeps no observation labels, so fixed_ou_solve trusts the supplied observation_index for row order: it checks the row count and each row’s site (from site_index, such as the fit’s ou_site_index, or the index’s site level) against the covariance, but not the time order within a site. Residuals must carry the units of \(H\).

For CO2 country totals, build \(Q\) with co2_country_functionals() and pass an UnresolvedFunctionalConditioning to co2_country_flux_outputs(). Its outputs then carry uncertainty_scope="complete_native" and the conditioning description; without it they remain "retained_state_conditional" and omit the unresolved native state.

The products record the reduction_identity() of their reduction. The reduced arrays alone cannot identify the native problem: if one observation sees either of two cells that \(B\) and \(\Pi\) treat alike, swapping the cells leaves \(C_\alpha\), \(H_\alpha\) and \(A\) unchanged but reverses the sign of \(Q B_\perp H^T\). The reduction therefore records a native_reduction_identity(). For built-in separable covariances and independent combinations of them, it hashes the covariance configuration, the native \(H\), \(\Pi\), \(m\), and the prolongation \(U_*\). Each reduction with a custom covariance action receives a fresh identity. For those actions, prepare the fit and products from the same call to reduce_native_gaussian and keep the issued identity with the fit. The reduction identity combines the native identity with a hash of \(C_\alpha\), \(H_\alpha\) and the exact \(A\), so anyone who stores the native identity and the reduced arrays, such as a prepared artifact, can recompute it and detect a changed \(A\). The conditioning must carry the identity recorded when the fit was prepared, and the two must be equal. \(Q m\) and \(D\) do not depend on \(H\), so products built with another observation operator are caught only by the identity. The identity is an exact hash, not a tolerance: take it from the same reduce_native_gaussian(functionals=...) call that produced the products, rather than recomputing it from another reduction. In addition, the products’ \(Q m\) and \(D\) must equal the map’s own \(A F m\) and \(A F U_*\), which rejects products prepared for another functional, partition or covariance.

Use the same \(A\) in the solve as in the products. The products use the exact \(B_\perp\), so pairing them with a truncated low-rank \(A\) mixes two covariance models: the conditional mean update can be inflated and the conditional covariance can lose positive semidefiniteness. Negative eigenvalues up to clipping_tolerance (default 1e-6) relative to the largest eigenvalue of the prior functional covariance \(Q B Q^T = Q B_\perp Q^T + D C_\alpha D^T\) are treated as roundoff and clipped before drawing. That scale is used because the drawn covariances are formed by subtracting terms of that size and can themselves be zero, as when the retained states resolve every functional. The most negative relative eigenvalue is recorded as conditional_covariance_min_eigenvalue. A larger negative eigenvalue raises an error instead of producing complete_native output. A FixedOuLowRank prepared with a full-width factor of the exact \(A\) gives the exact update with sampled OU amplitudes.

When retained states are marginalised into \(A\), openghg_inversions.coherent_reduction.marginalise_functional_states() moves their functional contribution into \(Q x_\perp\), matching a reduction with the kept rows of \(\Pi\). For CO2 country outputs, pass full-restriction products and declare the marginalised states on the conditioning; they must be exactly the fit’s inactive states, which are otherwise held fixed without their variance and make complete uncertainty undefined. Activity is read from the <flux_scale>_is_active mask that the fitted model records for every activity policy, including all-active; a trace without it is rejected.

Staged CO2 outputs#

Complete country totals require a supported fit and a prepared artifact with country products. See Outer-region flux states held or marginalised for the retained-state-conditional totals available with outer-flux marginalisation.

  1. Build \(Q\) from the signed reference flux the affine reconstruction will carry with co2_flux_country_functionals() and the reporting country file, and pass it to reduce_native_gaussian() with functional_dim="country_functional".

  2. prepare_co2_inputs() with aggregation_error_rank=None saves reduction.functional_products in the prepared artifact’s country_functionals node (schema version 4) and summarizes them under provenance["country_functionals"]. Only full-restriction products on the country_functional axis are accepted, and their reduction_identity must equal the artifact’s reduction_identity. The artifact records the reduction’s native_reduction_identity and recomputes the reduction identity from it and its stored alpha_prior_covariance, H and dense \(A\). This ties the products to the native observation operator, which the \(Q m\) and \(D\) checks cannot, and to the stored \(A\). The node stores the products’ identity, and load requires the restored artifact to reproduce it, so an operator or \(A\) changed after preparation is rejected. The unresolved covariance must be symmetric positive semidefinite.

  3. Replay (openghg_inversions.rhime.co2.handoffs.postprocess(), or run_co2()) rebuilds each posterior draw’s residual mf - model_mean and the fit’s own \((A + R)^{-1}\) with co2_unresolved_conditioning(), restricts the products to the requested countries, passes the artifact’s reduction identity, and labels country outputs "complete_native". The trace must carry the fitted model’s <flux_scale>_is_active mask. Without products they stay "retained_state_conditional". Native-grid flux is unchanged.

The products use the exact \(B_\perp\), so the joint covariance of the products and the observations is consistent only with the exact \(A\). An artifact with products must therefore store dense \(A\), and the fit samples the same \(A\) it is conditioned on. The solve follows the recorded likelihood. Additive-sigma and site-sigma fits use the stored \(A\) plus epsilon**2 - diag(A) for each draw, with the reported error variance as a lower bound. Fixed-OU fits, with fixed or inferred amplitudes, rebuild the fit’s FixedOuLowRank from the recorded observation error, OU site index and time scales (numeric hours, or a timedelta), with each draw’s amplitudes. Other likelihoods raise an error rather than claiming complete outputs. unresolved_conditioning records the \(A\) and noise model as JSON. A conditional-covariance eigenvalue below the clipping tolerance raises (see above), so no complete label is reported. Country sector totals are summed from the same complete (country, source) draws. States marginalised at preparation are declared from state_information_marginalised when the artifact records it.

Assumptions and limitations#

The native coordinates of the mean and sensitivity must match exactly. The function checks this before computing them, because xarray dot products would otherwise use an inner join and could silently omit unmatched native cells. The strategy’s input, a basis prolongation for PreserveBucketProlongation or a restriction for SuppliedRestriction, must use the same native grid. The covariance action checks that grid when it applies or solves with that input, which may happen after the mean and sensitivity have been computed.

The native mean and basis describe dimensionless scaling factors. Convert the sensitivity to the required observation units with OpenGHG’s Pint registry before calling the function. All rows of the current observation DataArray share one units attribute, so differently represented observations must not be stacked directly. For example, ppm rows cannot currently be combined with delta(O2/N2) rows expressed in per meg.

The retained states must not be redundant. The projection obtains a cheap condition estimate while factorizing \(C_\alpha\) and rejects a numerically ill-conditioned retained covariance. This usually means that two or more retained basis states describe nearly the same native variation.

For the Gaussian model above, \(A\) is the aggregation-error covariance. The function does not add observation or model-error covariance \(R\); likelihood construction must use the total \(R + A\). The reduction does not validate \(A\) independently. When \(A\) is converted to LRPD during CO2 preparation, or resolved as dense input at runner and serialization boundaries, it must be symmetric and positive semidefinite within its scale-based numerical tolerance; it may be singular. \(R\) is not used to rescue a materially indefinite \(A\). LRPD preparation retains only modes above that tolerance and carries the discarded marginal variance in the diagonal tail. Small negative tail entries caused by accepted roundoff are clipped to zero. Assess any low-rank-plus-diagonal approximation using the total likelihood covariance and its log density, particularly when model-mismatch error is small.

The conditional model is exact for a Gaussian native state and error independent of that state. Using the resulting moments with a LogNormal retained state is a moment-matched approximation. A positive sampled state requires a separately established positivity-preserving physical restriction, such as SuppliedRestriction with require_positivity_preserving=True. The bucket-compatible restriction derived by PreserveBucketProlongation is not guaranteed to preserve positivity.

The function does not construct a likelihood, approximate \(A\), or serialize the result. It reconstructs native quantities only as the linear functionals requested through functionals. Do not add another error term representing the same unresolved flux. Adding covariance components also assumes that their errors are independent unless their cross-covariances are included explicitly.

See openghg_inversions.coherent_reduction for the public interface.
