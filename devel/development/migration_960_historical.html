Released 0.7 migration evidence#

This page records historical evidence for issue #960, part of issue #944 and issue #948. It is an evidence record, not a promised converter interface. The comparison revision is compatibility-bearing devel 0a32d73a5c4a72be0505a4ed682472e1613e49e9. The parent migration ledger records current-source cases and follow-up owners. A removal PR must refresh evidence for affected files changed after that revision.

Source facts and scientific boundaries#

The following are source findings unless explicitly described above as observed. Their candidate replacements are decisions for issue #949 / issue #948; issue #719 owns preserving relevant scientific regressions during removal.

  • H1: Routes and omitted defaults. Released Python/installed RHIME uses draws/burn/tune/chains 1000/0/1000/4 and requires an explicit built-in or custom likelihood. The ordinary wrapper chooses pollution-event mismatch itself, uses the same sampler defaults when omitted, and selects legacy filenames/output. True --legacy-fixedbasis dispatches untranslated legacy parameters and defaults to nit/burn/tune/nchain 250000/50000/125000/2. Its x prior is truncated-normal sigma 1 and BC prior truncated-normal sigma 0.1; direct RHIME defaults instead to a reparameterized lognormal x prior and BC sigma 0.05. The true fixedbasis sigma prior is uniform [0.1, 3]; RHIME pollution-event’s unresolved sigma_prior=None becomes uniform [0, 0.1] at model construction. None in the observed JSON is the resolved configuration value, not a claim that no sigma prior exists. Candidate conversion must materialize route-specific defaults explicitly. Disposition: mechanical settings capture, with supported source coverage unresolved in #948; #949 owns conversion of those explicit defaults. Shared omitted defaults are use_bc=True, add_offset=False, offset normal(0,1), sigma_per_site=True, sigma_freq=None (one period), pollution_events_from_obs=False, power 1.99, and min_error=0.0. RHIME’s resolved sigma_freq_anchor is the run start date, even when the one-period choice makes it immaterial. The lower-level direct inferpymc API is another inspected signature: nit/burn/tune/nchain 20000/10000/10000/4, lognormal x, BC sigma 0.05, and uniform sigma [0.1,3]. It must not supply defaults for an omitted fixedbasisMCMC call.

  • H2: Sampling meaning. inferpymc passes draws=nit to its sampler; both released sampling bodies call pm.sample before slicing away burn posterior draws. Tune remains separate. The captured explicit wrapper request nit 7, burn 2, tune 3 means five retained draws per chain, not seven plus burn, and not five minus tuning. This is a mechanical spelling change with preserved meaning. Only RHIME slicing was executed using a mocked sampling boundary; the true inferpymc body was inspected. Candidate: explicit draws, burn and tune; disposition: mechanical. #949 owns conversion and #952 owns later numerical validation.

  • H3: Pollution-event offsets. With observed pollution scaling, the historical compatibility runner supplies only boundary_mean as the baseline. Modern construction includes the offset in the baseline. For Y=20, BC=10, offset=3, the old enhancement is 10, modern 7. Without BC, the old baseline is absent: it uses abs(Y) + 1e-6*mean(Y) (20.00002), while modern offset-aware scaling gives 17. This is a scientific change, not a mechanical rename. The likelihood otherwise forms sqrt(error**2 + (pollution_event*sigma)**power) with a minimum-error floor. The witnesses were derived from source, not evaluated as PyMC graphs. Candidate: explicitly choose the modern full-baseline pollution-event model or retain the original environment. Disposition: scientific change; #948 owns the choice, #949 its report, and #719 the affected regressions.

  • H4: Fixed-error exceptions. Historical pollution-event no_model_error retains a disconnected sigma variable and uses max(abs(error), 1e-12*nanmean(Y)) without the prepared minimum-error floor. For Y=[20,20], error=[0,2], min_error=[5,5], epsilon=[2e-11,2]. Its wrapper’s additive-sigma/no-model-error route separately preserves the minimum-error floor: error 2 and minimum 5 gives epsilon 5. Modern fixed error alone gives 2. Choosing which route to preserve requires explicit scientific review; restoring disconnected historical sigma in modern models is not proposed. Candidate: modern mismatch_model='fixed_error' after an explicit choice, or original 0.7 execution. Disposition: scientific change / unresolved supported subset; #948/#949 own selection/reporting and #719 regressions.

  • H5: Chain summaries. Released convert_idata_to_dataset discards all but chain zero, and true inferpymc’s result adapter also selects chain zero before generating its arrays. Raw InferenceData can still contain every chain. The observed synthetic released conversion gives mean 2 for chains [1,3] and [9,11]. Current merge_trace_groups retains chains and stats combines chain/draw at reduction, giving mean 6. Output consumers must acknowledge this scientific change; the evidence does not reinstate a modern chain policy switch. The current test test_modern_summary_pools_the_archived_chain_witness executes the modern reduction on the same plain witness. Candidate: modern all-chain summaries; disposition: scientific change. #948/#949 own the acknowledgement/report and #719 owns preservation of summary regressions.

  • H6: Output and Python consumers. Direct released RHIME returns RhimeResult with ArviZ idata, model/specs, outputs and optional inv_out. Ordinary wrapper main discards that return. True fixedbasis has format-dependent Dataset/dictionary/InversionOutput returns. Current full RHIME returns an InversionOutput with a DataTree trace, so a consumer such as result.idata.posterior needs an explicit rewrite. Released direct output defaults to inv_out with saving enabled; the wrapper defaults to legacy with save_inversion_output=False. Trace saving defaults false. A true/path save setting can request writing independently of a derived output mode. Derived filename conventions are evidence_ch4_EUROPE_2019-01-01.nc for direct RHIME and CH4_EUROPE_evidence_2019-01-01.nc for the wrapper. Default trace and inversion-output filenames respectively use evidence2019-01-01_trace.nc and evidence2019-01-01_inversion_output.nc. These filename/return bodies were inspected; no full output serialization or result-construction run occurred. Candidate: explicit output/save/filename settings and modern InversionOutput consumers. Disposition: mechanical settings with unresolved consumer automation; #945 owns the API, #949 output conversion, and #950 Python/batch launch adaptation.
