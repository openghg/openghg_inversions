openghg\_inversions.hbmcmc
==========================

The direct ``fixedbasisMCMC`` and ``inferpymc`` implementation was removed in
0.8. ``openghg_inversions.hbmcmc.run_hbmcmc`` remains as a transitional
old-INI-to-RHIME wrapper, with option translation in ``compatibility``.
See :doc:`../usage/legacy_and_migration`.
