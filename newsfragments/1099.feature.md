Pass a `CorrelatedPrior` with per-state `marginal` families and an optional `latent_correlation_floor` as the `retained_prior` of `prepare_co2_o2_inputs` to select copula marginals for linked CO2/O2 runs. The preparation keeps the solved latent correlation, so saved artifacts and the ordinary and cached linked runners reuse it without solving the copula again, and the runners record marginal counts and any latent-correlation repair in model metadata. Linked preparations are written as schema version 6; earlier linked preparations must be prepared again. `prepare_co2_inputs` takes the floor as an explicit `latent_correlation_floor` argument beside `prior_marginal`.
