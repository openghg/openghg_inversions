Fixed-OU CO2 runs can now sample the state at supplied OU site amplitudes on the cached route (fixed-θ state sampling). Set `likelihood.cached_state_quadratic = true` with `fixed_site_amplitudes`, given as values or as `{path = "...", statistic = "median"}` to summarise a previous run's `ou_site_amplitude` draws. The state quadratic is built once, and the run metadata records the amplitude source and that the posterior is conditional on it.
