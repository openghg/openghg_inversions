Configured CO₂ no longer accepts `sampling.nuts_sampler`; remove that setting.
Inference is selected from the scientific model: NumPyro NUTS for additive
sigma, PyMC NUTS for site sigma, scalar sigma and fixed-amplitude OU, and the
matched cached PyMC update for inferred-amplitude OU. This replaces the
template-wide NumPyro choice and the previous PyMC default when omitted.
Move inferred-OU `sigma_target_accept` and `state_target_accept` from
`likelihood` into `sampling`.
Python `co2.handoffs.sample` now accepts that `sampling` mapping in place of a
`RhimeSampler` override, using the same automatic policy as `run_co2`.
