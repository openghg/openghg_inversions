`ClassMixedExponentialCovariance` adds a non-separable native covariance option: chosen classes (for example inner land) use a dense geodesic exponential kernel `exp(-d_gc/ℓ)` with 111 km per degree, built and Cholesky-factorized once and checked for positive definiteness, while other classes keep the separable kernel. `IndependentSourceCovariance` accepts these blocks per source and serializes them as schema version 2; separable-only configurations and outputs are unchanged.
