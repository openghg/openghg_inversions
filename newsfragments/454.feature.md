`basis_algorithm = "region_constrained"` can now be configured in RHIME INI files and Python options. `region_classes` selects the class map (`path`, `variable`, `unmapped_values`); when omitted, `landsea_path` or the domain's packaged land/sea map is used. The map is loaded and checked before acquisition, and it also works with fixed InTEM outer regions. Nested runs can constrain the inner basis independently with `inner_region_classes`.
