`basis_algorithm = "region_constrained"` can now be configured in RHIME INI files and Python options. Select its class map with `region_classes_source` (`"landsea"` or `"file"` with `region_classes_path` and `region_classes_variable`). Optionally set `region_classes_unmapped_values`, `region_allocation` and `min_regions_per_class`. The map is loaded and checked before acquisition, and it also works with fixed InTEM outer regions.
