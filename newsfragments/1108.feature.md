`prepare_co2_inputs`, `run_co2` and the CO2 `prepare` handoff now choose the low-rank aggregation-error rank from the spectrum of the unresolved covariance whitened by a reference mismatch covariance, instead of a fixed rank of 512. `observation_error.WhitenedRankRule` holds the criteria: keep every mode with whitened eigenvalue above 0.1, optionally more to meet a dropped-mode KL budget, or take an explicit rank override that warns when it is below the rule rank. The rule requires a `reference_covariance` chosen by the caller, as a labelled observation-by-observation covariance in canonical order with squared mole-fraction units. Use `models.fixed_ou.fixed_ou_mismatch_covariance` to evaluate a reference from reported observation error, fixed site amplitudes and optional OU time scales, using the same site correlation as the likelihood. Callers that relied on the default rank must now pass a reference, an explicit integer rank (used as given when no reference is passed), or `None` for exact storage. Provenance `aggregation_error_rank_selection` records the reference description, the criteria, the count above the threshold, the chosen rank, the spectral dropped-mode KL and the KL of the stored representation at the reference. The selected rank, and so the downstream likelihood cost, now depend on the data and the basis. Re-preparing with supplied provenance no longer carries over earlier aggregation-error diagnostics.
