`prepare_co2_inputs`, `run_co2` and the CO2 `prepare` handoff now choose the low-rank aggregation-error rank from the spectrum of the unresolved covariance whitened by a reference mismatch covariance (`observation_error.WhitenedRankRule`: reported observation error plus an independent 1 ppm amplitude by default, keeping every mode with whitened eigenvalue above 0.1, optionally more to meet a dropped-mode KL budget), instead of a fixed rank of 512. Provenance `aggregation_error_rank_selection` records the reference amplitudes, the count above the threshold, the chosen rank and the dropped-mode KL. An integer rank is still accepted as an explicit override and warns when it is below the rule rank. The reference covariance is an explicit input to the spectrum (`ReferenceMismatchCovariance`, built by `reference_mismatch_covariance`), so other references can be screened.
