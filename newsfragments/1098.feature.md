Add Normal, Weibull and Gamma marginals to the Gaussian-copula flux prior alongside the default LogNormal. Python callers can pass labelled `prior_marginal` values to `prepare_co2_inputs` for ordinary and cached CO2 runs. Sampling Gamma marginals with NumPyro or BlackJAX needs TensorFlow Probability from the new optional `jax` extra (`pip install 'openghg-inversions[jax]'`); without it, JAX sampling of models that need it stops with an `ImportError` naming the extra. Known Gamma numerical limits are tracked in #1144.
