`prepare_observation_errors`, `filter_observations`, `build_sensitivities` and `assemble_inputs` (`assemble_rhime_inputs`) now pass per-site datasets between preparation steps instead of `MergedData`, which holds acquired data only. Call `prepare_observation_errors(merged.site_data, ...)`, then `filter_observations(site_data, merged.site_options, filters=...)`, which returns the retained datasets and their `SiteOptions`; `build_sensitivities` takes the site datasets and `assemble_inputs(site_data, basis_functions, site_options=..., ...)` takes the retained selectors. `make_standard_rhime_outputs` returns a new `RhimeResult` instead of modifying its argument. Standard staged envelopes (`prepare_rhime_stage` and related functions with `model="standard"`) and standard preparation manifests written before this change must be regenerated with `stages.prepare`.

Standard `run_rhime_from_prepared_inputs` no longer accepts complete `model_builder` customisation. Use `likelihood_builder` for a custom likelihood, or construct and sample a custom PyMC model directly. `build_standard_rhime_model_result` now takes `RhimeModelSpec` instead of an output-bearing `RhimeRunSpec`. Complete-model-builder compatibility remains available for multisector execution.
