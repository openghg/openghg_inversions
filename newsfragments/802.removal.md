`prepare_observation_errors`, `filter_observations`, `build_sensitivities` and `assemble_inputs` (`assemble_rhime_inputs`) now pass per-site datasets between preparation steps instead of `MergedData`, which holds acquired data only. Call `prepare_observation_errors(merged.site_data, ...)`, then `filter_observations(site_data, merged.site_options, filters=...)`, which returns the retained datasets and their `SiteOptions`; `build_sensitivities` takes the site datasets and `assemble_inputs(site_data, basis_functions, site_options=..., ...)` takes the retained selectors. Standard staged envelopes (`prepare_rhime_stage` and related functions with `model="standard"`) and standard preparation manifests written before this change must be regenerated with `stages.prepare`.

Replace standard `run_rhime_from_prepared_inputs(prepared_inputs=..., run_spec=...)`, including the 0.7 one-sector convention, with `run_standard(prepared=..., config=...)`. The old prepared entry point now retains only multisector compatibility. Standard custom likelihoods use `likelihood_builder`; whole standard graphs use direct PyMC construction. Standard construction uses one eager `build_standard_model` after explicit caller materialization.
