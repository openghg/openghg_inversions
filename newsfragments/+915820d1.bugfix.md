Region maps and country files now share one eager reader, `openghg_inversions.region_maps`. Basis support maps (land/sea classes, fixed outer regions) gain the HDF5 backend fallbacks previously used only for country files, and `utils.open_ds` falls back from xarray's default backend to `h5netcdf` with a `RuntimeWarning`. Country files that store codes as `region` now load with a `country` variable whichever backend succeeds, and a missing class variable raises `KeyError` (previously `ValueError` in `utils.get_country` and legacy outputs).
