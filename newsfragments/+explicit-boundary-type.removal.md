CO2 and CO2/O2 boundary tables now select their family with `type`: `"multiplicative"` (the default, as before centered boundaries were added) or `"additive"`. A table with `mean_shift_prior` and `anomaly_scale` but no `type = "additive"` is now rejected as having unknown multiplicative options instead of silently becoming additive. In Python, `MultiplicativeChoice.bind` accepts only centered sensitivity and the new `bind_absolute` binds absolute `H_bc`; recipes bind through `openghg_inversions.models.boundary.bind_prepared`, which checks the choice against the representation preparation recorded. Each choice class names its family in `kind`, which outputs record as `boundary_formulation`.
